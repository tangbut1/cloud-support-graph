### Day4-01-MCP工具与防越权实测.png（+ 同名 .txt）

- **图题建议**：图 5-4 MCP 工具调用与防越权（IDOR）实测
- **内容**：8 个板块，一条完整的"工具 + 安全"演示链路：
  1. MCP 服务端注册的 4 个工具；
  2. 身份上下文令牌（只显示前 40 字符，说明"只在后端内部流转"）；
  3. 张三调用 list_my_instances -> 3 台实例（含 swap、备案字段）；
  4. 诊断自己的实例 1 -> 4 条检查项（2 严重 + 1 警告）+ 结论 + 3 条建议动作；
  5. 张三诊断李四的实例 4 -> **PERMISSION_DENIED**（不泄露任何细节）；
  6. 篡改令牌签名 -> **AUTH_INVALID**；
  7. 工单草稿：关联自己实例成功（requires_human_approval=true），关联他人实例被拒；
  8. 大模型实际看到的工具参数 —— 只有 instance_id / title 等业务参数，**没有 auth_context_token、没有 user_id**。
- **可证明**：
  * 身份不在模型可见的 schema 中，模型无法指定"查谁的数据"（架构级防越权）；
  * 服务端两道校验（验签 + 资源归属）都生效，跨用户调用 100% 被拦截；
  * 诊断是确定性代码产出的结构化结论，不是模型编的。
- **复现命令**：`cd backend; .\.venv\Scripts\python.exe D:\dsh\tmp\day4_demo.py`
